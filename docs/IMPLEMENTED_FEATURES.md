## 3. 메인 화면 기능 (Home)

### 3.1 상단 영역

- **타이틀**: "지역 경험치 맵" / "방문한 지역을 기록하고 경험치를 쌓아보세요"
- **국가 선택 (CountrySelector)**: 일본/한국 전환 (현재 UI에서는 일본만 활성화된 상태로 구현 가능)

### 3.2 뷰 모드 전환

- **지도 보기**: Leaflet 기반 지도에서 지역 클릭으로 경험치 설정
- **리스트 보기**: 지역 목록을 카드 형태로 표시, 클릭 시 상세 모달
- **도쿄 시정촌 관리**: 도쿄 내 시정촌(구/시/정/촌) 단위 경험치 일괄/개별 관리 모달

### 3.3 메인 컨텐츠 영역

- **통계 패널 (StatsPanel)**  
  - 시스템 레벨, 총 경현치  
  - 방문 지역 수 / 전체 지역 수  
  - 달성률(%)  
  - 경현치 분포(미답, 통과, 접지, 방문, 숙박, 거주)  
  - 모바일에서 통계 보기/숨기기 토글
- **지도 (MapView)** 또는 **리스트 (RegionList)**  
  - 지도: 일본 47 도도부현(및 줌 시 시정촌) GeoJSON, 클릭/Shift+클릭으로 레벨 변경  
  - 리스트: 지역 카드 목록, 클릭 시 RegionModal

### 3.4 모달

- **RegionModal**: 지역별 경험치(경현도), 방문일, 메모, 방문 횟수/숙박일, 방문 기록(VisitList) 편집 및 저장/삭제
- **TokyoMunicipalityModal**: 도쿄 시정촌 목록 로드, 탭(전체/구/시/정·촌), 개별 레벨 변경, 일괄 설정

## 5. 지도(Map) 기능

| 기능 | 설명 |
|------|------|
| **MapView** | Leaflet + React-Leaflet, GeoJSON으로 일본 도도부현/시정촌 경계 표시 |
| **BoundaryTileLayer** | 타일을 경계 안쪽으로만 표시 (leaflet-boundary-canvas) |
| **줌 레벨** | 줌에 따라 도도부현 ↔ 시정촌 뷰 전환 |
| **지역 클릭** | 일반 클릭: 경험치 사이클(0→1→2→3→4→0), Shift+클릭: 상세 모달 |
| **경현치 색상** | 미답/통과/접지/방문/숙박/거주별 색상 (EXP_COLORS) |
| **라벨** | 지역명 라벨 (커스텀/네이티브/없음), 타일 언어(현지/한국어/일본어) |

---

## 6. 지역(Region) 관련 기능

| 컴포넌트/기능 | 설명 |
|---------------|------|
| **RegionCard** | 지역 카드 (이름, 경현치, 방문일 등) |
| **RegionList** | 지역 목록 나열, 클릭 시 RegionModal |
| **RegionModal** | 지역 상세: 경현도(0–5), 방문일, 메모, 방문 횟수, 숙박일, 방문 기록(Visit) 추가/편집, 저장/삭제 |
| **VisitList** | 방문 기록 목록 (시작일/종료일/제목 등) |
| **TokyoMunicipalityModal** | 도쿄 시정촌 데이터(N03-21_13_210101.json) 로드, 탭별 필터, 개별/일괄 경현치 설정, 부모(도쿄) 롤업 반영 |

---

## 7. 통계(Stats)

| 항목 | 설명 |
|------|------|
| **StatsPanel** | 시스템 레벨, 총 경현치, 방문 지역 수, 달성률(%), 경현치별 개수(미답~거주) |
| **저장소 연동** | Zustand 스토어의 `getTotalGyeonghyeonchi`, `getSystemLevel`, `getVisitedCount`, `getCompletionRate`, `getGyeonghyeonchiCounts` 사용 |

## 10. 데이터·상태 관리

| 항목 | 설명 |
|------|------|
| **Zustand 스토어** | `country`, `regions`, `selectedRegionId`, `settings` 등 상태 및 액션 |
| **persist** | localStorage에 맵 데이터·설정 저장 (키: STORAGE_KEYS.MAP_DATA) |
| **지역 데이터** | 일본 47 도도부현, 한국 17 시도, 도쿄 시정촌 GeoJSON 등 상수/파일 참조 |
| **경현치(경험 등급)** | 0 미답, 1 통과, 2 접지, 3 방문, 4 숙박, 5 거주 (ExperienceGrade / GyeongHyeonChi) |
| **시정촌 롤업** | 자식(시정촌) 경현치가 부모(도도부현)보다 높으면 부모 자동 상향 |
