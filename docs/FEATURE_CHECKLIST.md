# MAPEXP 개발 기능 목록

> MVP 구현을 위한 핵심 기능 체크리스트

## 1. 프로젝트 초기 설정

- [ ] React + Vite + TypeScript 프로젝트 생성
- [ ] Tailwind CSS 설정
- [ ] Zustand 상태 관리 설정
- [ ] 기본 레이아웃 (Header, Footer, Container)
- [ ] 라우팅 설정 (React Router)

## 2. 데이터 준비

- [ ] 일본 47개 도도부현 GeoJSON 수집
- [ ] 한국 17개 시도 GeoJSON 수집
- [ ] GeoJSON 최적화 (용량 축소)
- [ ] 지역 메타데이터 JSON 생성 (한글명, 영문명, 일본어명)
- [ ] `/public/geojson` 폴더에 배치

## 3. 타입 정의

- [ ] `RegionExp` 인터페이스 정의
- [ ] `ExpLevel` enum (0-4)
- [ ] `MapExpData` 전체 데이터 구조
- [ ] `RegionMetadata` 지역 정보 타입

## 4. 상태 관리 (Zustand)

- [ ] Store 생성 및 persist 설정
- [ ] State 정의
  - `regions: RegionExp[]`
  - `selectedCountry: 'JP' | 'KR'`
  - `selectedRegion: string | null`
- [ ] Actions 구현
  - `addRegion()`
  - `updateRegion()`
  - `deleteRegion()`
  - `setCountry()`
- [ ] Computed values
  - `getTotalExp()`
  - `getVisitedCount()`
  - `getCompletionRate()`

## 5. 지도 시각화

### 5.1 기본 지도 컴포넌트

- [ ] 국가 선택에 따라 지도 변경 (일본/한국)
- [ ] 줌/팬 컨트롤

### 5.2 인터랙티브 기능
- [ ] 지역 호버 시 툴팁 표시 (지역명 + 경치 레벨)
- [ ] 지역 클릭 시 선택 처리
- [ ] 경치 레벨에 따른 색상 표시

  - 4: 빨강 (거주)
- [ ] 지역 데이터 변경 시 색상 자동 업데이트
