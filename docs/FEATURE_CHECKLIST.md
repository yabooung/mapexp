## 1. 프로젝트 초기 설정

- [ ] React + Vite + TypeScript 프로젝트 생성
- [ ] Tailwind CSS 설정
- [ ] Zustand 상태 관리 설정
- [ ] 기본 레이아웃 (Header, Footer, Container)
- [ ] 라우팅 설정 (React Router)

## 2. 데이터 준비

- [ ] 일본 47개 도도부현 GeoJSON 수집

- [ ] GeoJSON 최적화 (용량 축소)

- [ ] `/public/geojson` 폴더에 배치

## 3. 타입 정의

- [ ] `RegionExp` 인터페이스 정의
  - [ ] `visitCount` 필드 추가 (방문 횟수)
  - [ ] `totalNights` 필드 추가 (누적 숙박일)
- [ ] `ExpLevel` enum (0-5, 6단계)
  - 0: 미방문, 1: 통과, 2: 짧은 방문, 3: 긴 방문, 4: 숙박, 5: 마스터/거주
- [ ] `MapExpData` 전체 데이터 구조
- [ ] `RegionMetadata` 지역 정보 타입

## 4. 상태 관리 (Zustand)

- [ ] Store 생성 및 persist 설정
- [ ] State 정의

  - `selectedCountry: 'JP' | 'KR'`

- [ ] Actions 구현
  - `addRegion()`
  - `updateRegion()`
  - `deleteRegion()`
  - `setCountry()`
- [ ] Computed values
  - `getTotalExp()` - 레벨 5는 8점으로 계산
  - `getVisitedCount()`

### 5.2 인터랙티브 기능

## 우선순위

### 🔴 High (필수)
- 프로젝트 초기 설정
- 데이터 준비 (GeoJSON)
- 타입 정의 (0-5 레벨 시스템)
- 지도 시각화 (레벨별 색상, 레벨 5 금색)
- 지역 선택 UI (레벨 5 선택 가능)
- LocalStorage 저장
- 통계 패널 (마스터 지역 수 표시)
- 공유 기능 (URL)

### 🟡 Medium (중요)
- 지역 리스트 & 검색
- 레벨 5 확인 메시지 및 검증
- 방문 횟수/숙박일 입력 (레벨 5용)
- 마스터 뱃지 기본 (첫 마스터, 트리플 마스터)
- 데이터 가져오기/내보내기
- 이미지 공유
- 반응형 디자인
- 로딩 & 에러 처리

### 🟢 Low (부가 기능)
- 레벨 5 빛나는 애니메이션
- 마스터 달성 축하 애니메이션
- 고급 마스터 뱃지 (레전드, 그랜드 마스터)
- 자동 방문 횟수 추적 (Phase 2)
- 마스터 리더보드 (Phase 2)
- 애니메이션
- QR 코드
- SNS 공유 버튼
- E2E 테스트
- 모니터링
